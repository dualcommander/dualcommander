# Minimal README

- Keep README.md a short entry point: app purpose, downloads, essential quick-start commands, and links.
- Do not append feature inventories, language lists, implementation details, configuration reference, CI explanations, or release procedures.
- Put developer setup and Make commands in CONTRIBUTING.md; link detailed user instructions from docs/ or the user manual.
- Link existing documentation rather than duplicating it. Remove obsolete or redundant text when editing.
- Preserve security warnings and installation prerequisites beside any commands moved to detailed documentation.
- Verify local links after changes. Do not create documentation for unrequested future features.
